AppointMate: Healthcare Appointment Management System

Overview
AppointMate is a web-based healthcare appointment management system that streamlines the process of booking doctor appointments and diagnostic tests. The platform offers patients a centralized dashboard to manage healthcare appointments, view prescriptions, and track medical tests through an intuitive and user-friendly interface.

Technology Stack
The project is built using core web technologies:
HTML5 - Structure and content markup
CSS3 - Styling, responsive layouts, and visual design
JavaScript (ES6) - Client-side interactivity and dynamic content loading
External Libraries: html2pdf.js (for PDF receipt generation), Google APIs (for authentication)

Key Features
1. No Overlapping Appointments/Tests
2. Prerequisite Information Before Booking
3. Downloadable Receipts
4. User-Friendly Interface
